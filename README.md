# BNurs Curriculum Map

A web-based curriculum mapping project for the BNurs program.

## Overview

This repository contains a JavaScript/CSS/HTML application for organizing and visualizing BNurs curriculum structure.

## Tech Stack

- JavaScript (59.2%)
- CSS (33.1%)
- HTML (7.7%)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/DNMSW/BNurs-Curriculum-Map.git
   cd BNurs-Curriculum-Map
   ```
2. Open `index.html` in your browser, or serve the project with a local static server.

## Project Structure

- `index.html` – application entry point
- `style.css` / `styles.css` – styling
- `*.js` – application logic
